## Overview

Samba Shares installs and manages Samba on your hosts over SSH. Each host gets its own tab for shares, users, folder permissions, live sessions, the config and the logs.

Read the [docs](https://docs.termix.site/plugins/samba) to set it up and use it.

<br />

## Features

- Install Samba and start, stop or restart it from Termix
- Create, edit and delete shares with access options
- Samba users, passwords and Linux groups
- Owner, mode and ACL entries for share folders
- Connected users, open files and disconnect
- Config check with testparm and a log viewer
- Your own smb.conf is never rewritten, shares live in one included file
